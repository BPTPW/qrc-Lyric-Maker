# QRC Lyric Maker
A web-based character-by-character lyric maker program

Creates character-by-character lyrics compatible with Lyricify 4.0, allowing you to create scrolling character-by-character lyrics more conveniently and quickly

## Download and Usage

Download and open the [index-en.html](https://github.com/YESNLars/qrc-Lyric-Maker/blob/main/index-en.html) file with your browser to use it

Or visit (https://bptpw.github.io/qrc-maker/)
